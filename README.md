## Features

### Custom Private Match Code Maker
This tool uses the official SUPREM.IO API to generate custom private matches directly. 
* **Troubleshooting:** If the private match maker fails to load or generate a code, simply refresh the game page.

### Information Mod
An information hud that shows all important stats display. It can be customized further within the standard in-game settings menu. The overlay displays:
* Current player velocity
* Remaining player lives
* Opponent health tracking

## No Unfair Advantages
The Information Mod does not provide any unfair advantages. It does not look up hidden data; it collects information that is already visible to you on the standard tab list and displays it in a continuous on-screen overlay so you do not have to hold tab in a distracting menu to view essential info.

## Installation and Requirements
To run these scripts, you will need a userscript manager extension installed in your web browser. 

1. Install a userscript manager (such as Tampermonkey, Violentmonkey, or Greasemonkey).
2. Click the file you want, it should open a install prompt.
     If this doesn't work, download the file, and manually import it into your userscript manager.
3. Try out theses addons on SUPREM.IO
